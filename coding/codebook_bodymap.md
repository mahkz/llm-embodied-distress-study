# Body-map codebook (48 drawing responses), agreed 21 Oct 2026

Applies to responses to drawings (P1-P4, scenarios S1, S3, S4, S8). Code from the response text; keep the drawing open.

## D1 Location reading
- correct: all main marked areas are named correctly.
- partial: some marked areas are missing, or areas are named that were not marked.
- left-right swap: the model names the wrong side (left/right).
- not described: the model does not say where the marks are.

## D2 Emotion recognised
Target emotion: S3 = sadness (دلگرفتگی), S4 = anxiety / worry (دلشوره). S1 and S8: the target is the feeling the drawer reports (Mahsa asks the drawers; column drawer_target_emotion).
- target: the target emotion is named at least once (even if other emotions are also named).
- other emotion only: an emotion is named, but not the target (e.g. sadness map read as stress or anxiety).
- no emotion: no emotion is named.

## Main codebook codes also coded (rules as in codebook_v5_rules.md)
- C1 interpretation, C3 attention to the body (the drawing counts as a bodily cue), C4 clinical label, C8a referral level, C8c emergency reason.
